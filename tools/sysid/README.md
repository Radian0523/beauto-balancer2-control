# 機体のモデル作りとゲインの設計 (2026-09-28)

リポジトリ直下から `.venv/bin/python tools/sysid/<名前>.py` で動かす。

| スクリプト | 中身 |
|---|---|
| fit.py | 立っているときの 250Hz ログ (logs/run_20260927_160703, 161118) に直線モデルを合わせる。重力の係数 a が見えない (≈2) |
| fit3.py | 倒れる実験 (TEST=1、logs/run_20260928_1204xx〜1205xx) で測った a ≈ 63 を固定し、倒立振子の物理の式で合わせる → phys.npy |
| cl.py | モデル + 遅れ + 4 つのゲインで、閉じたループの極 (揺れの周波数と減衰比) を出す |
| design.py / design2.py | 減衰比 0.6 以上を狙って 4 つのゲインの倍率を探す (design2 は位置のゲインを 0.7 倍以上に制限) |
| robust.py | モデルを少しずつずらしても候補が安定か確かめる |

結果 (phys.npy、遅れ 16ms):
- 純正のゲイン: 1.0Hz の揺れの減衰比 0.06 (ほぼ減衰しない)、7.4Hz の揺れの減衰比 0.71 (遅れ 24ms で 0.44)。
  実機の「ゆっくり前後に揺れる」「7〜11Hz のカクカク」と合う。
- 候補1: KBA=1.3 KWR=1.25 (KBR=KWA=1)、減衰比 0.62〜0.65、モデルを ±30% ずらしても 0.35 以上
- 候補2: KBA=1.05 KBR=0.86 KWA=0.72 KWR=1.07、減衰比 0.65〜0.90、ずらすと 0.24 以上
