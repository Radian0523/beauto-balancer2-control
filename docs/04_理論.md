# 自分で導いて説明できるようにする

当日 TA や審査員に「なんでそれで立つの？」と聞かれて **黒板で 5 分で説明できる** ことを目標にした資料。
数式は全部この機体の実数値付きで書いてあるので、数字を覚えれば説得力が出る。

---

## 1. 運動方程式を 5 分で導く（ラグランジュ法）

### 座標の取り方（ここだけ気をつければ後は機械的）

- `φ` … 車輪の**絶対**回転角。転がり拘束より進行距離 `s = rφ`。
- `θ` … 本体の**鉛直（重力方向）からの**傾き。前傾が正。
- `α` … 路面の勾配（登りが正、区間内は一定）。

⚠️ **エンコーダが測るのは `φ` ではなく `φ − θ`**。モータのステータが本体に固定されているので、
エンコーダは「本体に対する車輪の相対回転」しか見ていない。ここを間違えると全部ずれる。

### 運動エネルギー

車輪中心の速度は斜面方向に `rφ̇`、本体重心はそれに腕 `l` の回転が乗るので

```
v_b² = r²φ̇² + l²θ̇² + 2 r l φ̇ θ̇ cos(θ+α)
T = ½(m_w r² + J_w + 2J_rotor n²)φ̇²  +  ½ m_b v_b²  +  ½ J_b θ̇²
U = (m_b+m_w) g r φ sinα  +  m_b g l cosθ
```

> **`2 J_rotor n²` を忘れない。** 減速比 21 の二乗で効くので、この機体では
> 車輪側等価慣性 `Jw_eq = 9.13e-5` の **97% がモータロータ**。ここを落とすとモデルが合わない。

### オイラー・ラグランジュ方程式

`d/dt(∂L/∂q̇) − ∂L/∂q = Q`、モータトルク `u` は本体と車輪の**間**に働くので `Q_φ = +u, Q_θ = −u`。

```
M₁₁ φ̈ + m_b r l cos(θ+α) θ̈ − m_b r l sin(θ+α) θ̇² + m g r sinα = u − c(φ̇−θ̇)
M₂₂ θ̈ + m_b r l cos(θ+α) φ̈ − m_b g l sinθ                      = −u + c(φ̇−θ̇)

M₁₁ = m r² + Jw_eq = 1.575e-4,  m_b r l = 2.128e-4,  M₂₂ = m_b l² + J_b = 9.548e-4
```

θ 側の式では**コリオリ項がきれいに相殺する**（`∂L/∂θ` の項と打ち消し合う）。手計算の検算に使える。

### ここから読み取れる一番大事なこと

**勾配 α は φ の式にしか現れない。** つまり

```
坂 ≡ 車軸まわりの一定外乱トルク   τ_d = − m g r sinα
```

坂も、段差も、積載の偏りも、転がり抵抗も、**全部まとめて「1個の外乱トルク τ_d」**として扱える。
設計全体がこの1行の上に乗っている。

### 線形化（θ, α ≈ 0）

```
M₁₁ φ̈ + m_b r l θ̈ = u + τ_d − c(φ̇−θ̇)
M₂₂ θ̈ + m_b r l φ̈ − m_b g l θ = −u + c(φ̇−θ̇)
```

`x = [φ, θ, φ̇, θ̇]ᵀ` として `ẋ = Ax + Bu + B_d τ_d`。

**数値で押さえる 3 つ**
| | 値 | 意味 |
|---|---|---|
| 不安定極 | **12.1 rad/s**（時定数 **83 ms**） | 何もしないと 0.4 秒で倒れる |
| `m_b g l` | **0.0994 N·m/rad** | 1° 傾くと 1.7 mN·m の転倒トルク |
| `u→φ` の零点 | **±9.2 rad/s** | 右半面零点 ＝ **非最小位相** |

## 2. 非最小位相：この機体が本質的に難しい理由

`u→φ` の伝達関数は **右半面に零点 z = +9.2** を持つ。
物理的には「**前に進むには、まず車輪を前に出して体を後ろに倒す**」＝ 最初は逆に動く、ということ。

不安定極 `p = 12.1` と右半面零点 `z = 9.2` が**同時にある**とき、感度関数には破れない下限がある：

```
‖S‖∞ ≥ |z+p| / |z−p| = (9.2+12.1)/|9.2−12.1| = 7.4  ( ≈ 17 dB )
```

**どんな制御則を使っても**外乱抑圧のピークは 17 dB より良くできない。ここから実務的な結論が出る：

- **位置（φ）を速く制御しようとしてはいけない。** 帯域は zに対してかなり低く抑えるしかない。
- だから走行中は**位置ではなく速度を制御する**（LQI サーボ）。位置を戻す必要があるのはゾーンA だけ。
- 実際の設計の閉ループ極は **2.2 ± 1.8j rad/s**。z=9.2 の 1/4 程度で、上の制約と整合している。

「なぜ PID で粘るとダメか」の答えもここにある。PID は 1入力1出力の枠組みなので、
**2自由度（θ と φ）を 1 入力で同時に面倒を見る**この系では、どの出力に PID を掛けるか選んだ時点で
もう片方が野放しになる。純正が 4 状態フィードバックなのはそのため。

## 3. LQR：ゲインを「回す」のをやめる

```
J = ∫ (xᵀQx + uᵀRu) dt  を最小にする u = −Kx,   K = R⁻¹BᵀP
P は代数リカッチ方程式  AᵀP + PA − PBR⁻¹BᵀP + Q = 0  の正定解
```

- **なぜ極配置でなく LQR か**：極を 4 個選ぶのは「答えを直接決める」作業で、物理的な根拠がない。
  LQR は「**何をどれだけ嫌うか**」を決めるだけで、最適な極は勝手に決まる。
  さらに LQR は**位相余裕 60°・ゲイン余裕 (1/2, ∞)** を自動的に持つ（状態FBに限る）。
- **重みの決め方（Bryson の規則）**：`Q_ii = 1/x_i,max²`, `R = 1/u_max²`。
  「傾きは 0.12 rad まで、速度は 25 rad/s まで、トルクは 0.06 N·m まで許す」と**物理で宣言する**。
  この機体での結果：`K = [-0.0075, -0.673, -0.0064, -0.0517]`（u[N·m] = −Kx）。
- **符号の直感**：`K_φ` と `K_θ` が同符号になるのは非最小位相のため。
  「前に流されたら、いったん**さらに前に**車輪を出して体を起こしてから戻す」という動きになる。

### LQI（積分型サーボ）
走行中は `z = [θ, φ̇, θ̇, ∫(φ̇−φ̇_ref)]` を使う。積分器を入れる理由は**内部モデル原理**：
一定外乱（＝坂）と一定目標を定常偏差ゼロで扱うには、ループ内に `1/s` が要る。
ただし積分は遅い。だから次の「外乱を測って先に打つ」と組み合わせる。

## 4. 加速度センサが無いのに、なぜ絶対角が分かるのか（ここが一番のウリ）

**手で示せる。** 線形化した θ の式を θ について解くだけ：

```
θ = ( M₂₂ θ̈ + m_b r l φ̈ + u ) / (m_b g l)
```

右辺に必要なもの:
- `θ̈` … ジャイロを**微分**すれば出る。**しかもバイアス b は微分で消える**（b は定数なので）。
- `φ̈` … エンコーダ出力 `y = φ − θ` の 2 階微分 `ÿ` を使って `φ̈ = ÿ + θ̈`。
- `u`  … 自分が出したトルク（電流指令なので既知）。

つまり **「エンコーダ＋ジャイロ＋自分の出したトルク＋運動方程式」だけで絶対角が復元できる**。
同じ理屈で外乱トルクも出る：`τ_d = M₁₁φ̈ + m_b r l θ̈ − u`。

> **では、なぜ素直に 2 階微分しないのか。**
> ジャイロの分解能は 1.2 deg/s しかなく、2 回微分したら雑音しか残らないから。
> **カルマンフィルタは、この「原理的には解ける計算」を雑音に対して最適に行う装置**。
> 可観測性（＝原理的に解けること）は上の式で保証されていて、KF はその実行方法にすぎない。

### カルマンフィルタの中身（6状態）

```
x̂ = [φ, θ, φ̇, θ̇, b_gyro, τ_d]ᵀ
予測:  x̂⁻ = A_d x̂ + B_d u
更新:  x̂  = x̂⁻ + L ( y − C x̂⁻ ),   y = [ φ−θ , θ̇+b ]ᵀ
```

- `L` は**定常カルマンゲイン**（離散リカッチ方程式の解）。オフラインで計算して 6×2 の定数行列を焼くだけ。
  LPC1343（FPU 無し・72 MHz）でも 500 Hz で余裕。
- **推定器と制御器は双対**：LQR が `(A,B,Q,R)` のリカッチなら、KF は `(Aᵀ,Cᵀ,Q_process,R_noise)` のリカッチ。
  同じ方程式を転置して解いているだけ、と言えると理解が伝わる。
- **分離定理**：線形・無飽和なら「LQR を設計」→「KF を設計」→「繋ぐ」で閉ループ極は両者の極の和集合になる。
  だから別々に設計してよい。**ただし飽和があると崩れる**（→ だから制御配分とガバナを入れている）。
- `b_gyro` を状態に入れる ＝ ドリフトを**モデル化して引き算する**。
  相補フィルタ/HPF は「ドリフトを高域通過で捨てる」ので、**定常的な傾きも一緒に捨ててしまう**。これが坂で負ける理由。

## 5. 外乱を「測って先に打つ」

τ̂_d が分かれば、その坂での平衡点を直接計算できる。定常（φ̈=θ̈=0）を置くだけ：

```
φ 式:  0 = u_eq + τ_d        →  u_eq = −τ_d
θ 式:  −m_b g l θ_eq = −u_eq  →  θ_eq = u_eq /(m_b g l) = −τ_d /(m_b g l)
```

**坂では「坂の分だけ前傾する」のが正解**。15° の坂なら θ_eq = 3.1°。
積分器が効いてくるのを待たず、坂に入った瞬間に姿勢目標を切り替えられる。

> **罠（必ず説明できるようにしておくと強い）**
> `u = u_eq − K(z − z_ref)` で θ_eq を丸ごと使うと
> `∂u/∂τ̂_d = −1 + K_θ/(m_b g l) ≈ +6.4` の**正帰還**になる。
> τ̂_d は入力ゲイン（Kt・ギヤ効率）の同定誤差も吸い込むので、
> **ループゲイン ≈ 6.4 ×(ゲイン誤差)**。誤差 16% 超で発振する。実験で踏んだ。
> 対策は `k_ff=0.6`・`θ_eq` を ±6° で飽和・τ̂_d を 0.2 s で低域通過・そして駆動ゲインの同定。

## 6. 実装（離散化と計算量）

- 制御周期 2 ms（500 Hz）。倒れる時定数 83 ms に対し 41 サンプル/時定数。十分。
- 離散化は零次ホールド：`A_d = exp(A·Ts)`。`scipy.linalg.expm` で一発（`design.py` 参照）。
- 1 周期あたりの浮動小数演算は約 60 回（6×6 行列ベクトル積が主）。72 MHz・FPU 無しでも 1% 未満。
- `double` は使わず `float`。ゲインは全部コンパイル時定数（`gains.h` を自動生成）。

## 7. 想定問答（これだけ答えられれば大丈夫）

| 質問 | 答えの骨子 |
|---|---|
| なぜ PID では足りない？ | 1入力で 2自由度（θ と φ）を同時に扱う必要がある。純正の既定制御も実は 4状態フィードバック。 |
| 加速度センサ無しでどうやって角度を？ | θ = (M₂₂θ̈ + m_b r l φ̈ + u)/(m_b g l)。ジャイロの微分でバイアスは消える。KF はその最適な実行方法。 |
| カルマンと相補フィルタの違いは？ | モデルを使うか使わないか。HPF は定常的な傾きを必ず捨てるので坂で誤る。 |
| LQR の重みはどう決めた？ | Bryson の規則。許容する振れ幅とトルクを物理で宣言した。 |
| なぜ坂で前傾するのが正解？ | 車輪の保持トルクの反力を重力トルクで釣り合わせる必要があるから。θ_eq = −τ_d/(m_b g l)。 |
| 制御周期は？ | 500 Hz（ジャイロ取得 2 ms に同期）。倒れる時定数 83 ms に対し十分。 |
| 位置制御を速くできないのはなぜ？ | 右半面零点 9.2 と不安定極 12.1 があり ‖S‖∞ ≥ 7.4 の下限が立つから。 |
| 飽和したらどうする？ | 倒立チャンネル優先の制御配分＋アンチワインドアップ＋参照ガバナ（目標速度を落とす）。 |
| モデルが違ったら？ | 当日 10 分で同定（振り子落とし＋車輪空転）。±20〜30% ずれても完走することはシミュレーションで確認済み。 |
| 一番効いた工夫は？ | 外乱トルクを状態に入れたこと。角度推定誤差 10.2°→0.18°、完走率 81%→100%。 |
