# 開発手順 (Mac)

すべてリポジトリ直下の `./bb2` で行う。`./bb2 help` で一覧。

## いつもの 1 サイクル

| やること | コマンド | 機体の状態 |
|---|---|---|
| ファームを書き込む | `./bb2 flash v5` (値を変えるなら `./bb2 flash v5 VMAX=0.25`) | ボタンを押しながら USB を挿す (書き込みモード)。sudo のパスワードを聞かれる |
| 走らせる | ― | USB を抜く → ボタン → 校正 5 秒 → 立ててボタン |
| ログを見る | `./bb2 log` | 止めたら電源を切らずに USB を挿す。logs/ に PNG と CSV、集計も表示 |
| リアルタイムで見る | `./bb2 live` | ケーブルを繋いだまま走らせる。logs/live_*.csv に全部保存 (時間制限なし) |
| ログを比べる | `./bb2 stats` (最新 3 本) / `./bb2 stats logs/run_A.csv logs/run_B.csv` | ― |

## 調整できるパラメータ (v5、make の引数。本体は firmware/main.c)

| 引数 | 意味 | 初期値 |
|---|---|---|
| `FFK` | 前傾フィードフォワードの係数 (v5 では 1) | 1 |
| `TI` | 積分の時定数 [s]。小さいほど強い。0 で無効 | 2 |
| `VMAX` | スティック最大の速度 [m/s]。0.5 だと坂の入り口で力が足りない | 0.3 |
| `VFAST` | R2 を押している間、スティックに触らなくても進む速さ [m/s] (いそいそモード。段差を勢いで越える) | 0.5 |
| `BTNSLOW` / `BTNFAST` | ゆっくり (R1) / いそいそ (R2) のボタンのビット。`./bb2 pad` の「押されたビット」で確かめる | 0x0008 / 0x0002 |
| `VSLOW` | R1 を押している間、スティックに触らなくても進む速さ [m/s] (ゆっくりモード。シーソーはボタンを押し続けて渡る)。スティックを半分引くと停止、引ききると後退 | 0.08 |
| `VBACK` | 後退の最高速度 [m/s]。後退 0.47 からの減速で倒れた | 0.3 |
| `ACC` | 加速度の上限 [m/s²] | 0.5 |
| `BOOST` | ボタンでダッシュしたときの速度 [m/s]。0 で無効 (VMAX を上げたので既定は無効) | 0 |
| `BACC` | ダッシュの加速度 [m/s²] | 0.6 |
| `EMAX` | 走行中の目標とのずれの上限 [rad] (1 rad = 2.1 cm) | 4 |
| `SMAX` | 車輪の速さのずれ (前後の平均) の上限 [m/s]。0.1 はふだんのブレーキを弱めて発散。0 で無効 | 0.4 |
| `VBW` | 車輪速度オブザーバの帯域 [Hz] | 20 |
| `KCP` | 純正ライブラリの電流制御の P ゲインの倍率。純正 (1) は電流の立ち上がりが約 100ms と遅く、4 で 5ms になり走りがはっきり安定した | 4 |
| `KCI` | 同じく I ゲインの倍率 | 1 |
| `KBA` | 本体の傾きのゲイン (K1) の倍率 (純正 = 1) | 1.3 |
| `KWA` | 車輪の位置のゲイン (K3、積分にも効く) の倍率 (純正 = 1) | 1 |
| `KBR` | 本体角速度のゲインの倍率 (純正 = 1)。細かい振動を減らす試し用 | 1 |
| `KWR` | 車輪角速度のゲインの倍率 (純正 = 1)。同上 | 1.25 |
| `BL` | ギアのガタの補償の強さ [電流指令] (力の向きに合わせて足す)。0 で無効 | 0 |
| `BLW` | ガタの補償が効き始める幅 [電流指令] | 500 |
| `BZT` | 釣り合う角度を覚え直す時定数 [s] (スタート直後 3 秒は 0.7 s)。スタート時の持ち方のずれを消す。0 で無効 | 2 |
| `GTRIM` | 走行中のジャイロ 0 点補正の時定数 [s]。校正のずれを走りながら直す。0 で無効 | 5 |

## ログの読み方

- 記録は最後の約 6.3 秒 (25Hz)。`LOGSET=2` で 6 変数だけの小さい記録にすると 13.6 秒 (125Hz の `LOGDIV=4` なら 2.7 秒)。`./bb2 build v5 LOGDIV=2` で 250Hz・約 0.8 秒 (振動の周波数を見るとき)。
- 実際の電流 (左右) も記録している。`./bb2 stats` の「電流の追従」が速いときに下がるなら、電圧が限界で指令どおりの力が出ていない。
- 止めた直後にもう一度スタートすると記録は消える。止めたら先に吸い出す。
- 立っている間ずっと 11Hz の細かい振動がある (ギアのガタと純正ゲインの自励振動)。純正でも出る。
  11Hz ノッチで消そうとしたら 6Hz で悪化したので放置 (ノッチのコードは削除済み。git tag before-refactor に残っている)。

## 分かっていること (2026-09-27)

- Mac では書き込みモードのドライブがマウントされない → `tools/flash_mac.py` が USB で直接書く。
- `-O0` でビルドすること。`-Os` だと純正サンプルすら立たない。
- memmap は 360 バイトあるが、USB とフラッシュ保存は先頭 352 バイトだけ (GAIN_OPTION6 は範囲外)。
- USB 通信: 64 バイトの HID レポート。`'R', 番地(下位,上位), 長さ` で読み、`'W', 番地, 長さ, データ` で書く、
  `'F','M'` でフラッシュ保存。0x1000 番地からはログ用バッファ (srcbuf)。

## コードの読み方

`firmware/main.c` の先頭コメントに 1 周期の流れと「純正のまま使っているもの」がまとまっている。
純正の元の制御は `firmware/vendor/control.c` の `Control()`。`main.c` の `control()` と並べると足した部分がわかる
(足した行には `[v5]` と書いてある)。

v3・v4 と、効果がなかったノッチフィルタは 2026-09-27 の整理で削除した。必要なら `git show before-refactor:firmware/main.c`。
