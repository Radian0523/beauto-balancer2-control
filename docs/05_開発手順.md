# 開発手順 (Mac)

すべてリポジトリ直下の `./bb2` で行う。`./bb2 help` で一覧。

## いつもの 1 サイクル

| やること | コマンド | 機体の状態 |
|---|---|---|
| ファームを書き込む | `./bb2 flash v5` | ボタンを押しながら USB を挿す (書き込みモード)。sudo のパスワードを聞かれる |
| パラメータを見る | `./bb2 get` | 電源 ON で USB を挿す (ボタンは押さない) |
| パラメータを変える | `./bb2 set vmax=0.25 boost=0.3` | 同上。書き込み直し不要、次に走らせたときから効く |
| 変えた値を残す | `./bb2 save` | 同上。電源を切っても残る (ファームを書き込み直すと初期値に戻る) |
| 走らせる | ― | USB を抜く → ボタン → 校正 5 秒 → 立ててボタン |
| ログを見る | `./bb2 log` | 止めたら電源を切らずに USB を挿す。logs/ に PNG と CSV |

## 調整できるパラメータ (v5)

| 別名 | 意味 | 初期値 |
|---|---|---|
| `ff` | 前傾フィードフォワードの係数 (加速度 a に対して a/g × ff だけ前傾させる) | 1.0 |
| `ti` | 積分の時定数 [s]。小さいほど強い。0 で無効 | 2.0 |
| `vmax` | スティック最大の速度 [m/s] | 0.2 |
| `acc` | 加速度の上限 [m/s²] | 0.5 |
| `boost` | ボタンでダッシュしたときの速度 [m/s]。0 で無効 | 0.25 |
| `bacc` | ダッシュの加速度 [m/s²] | 0.6 |
| `emax` | 走行中の目標とのずれの上限 [rad] (1 rad = 2.1 cm)。段差で飛び出さないため | 4.0 |
| `jerk` | 加速度の変化率の上限 [m/s³] | 3.0 |
| `body` / `wheel` | 純正ゲインの倍率 (GAIN_BODY / GAIN_WHEEL) | 1.0 |

memmap の名前 (`GAIN_BODY_ANGLE` など) も直接 `get` / `set` できる。

## ログの読み方

- 記録は最後の約 10 秒 (25Hz)。`./bb2 build v5 LOGDIV=2` で 250Hz・約 1 秒 (振動の周波数を見るとき)。
- 止めた直後にもう一度スタートすると記録は消える。止めたら先に吸い出す。
- 立っている間ずっと 11Hz の細かい振動がある (ギアのガタと純正ゲインの自励振動)。純正でも出る。
  11Hz ノッチで消そうとしたら 6Hz で悪化したので、今は放置している。

## 分かっていること (2026-09-27)

- Mac では書き込みモードのドライブがマウントされない → `flash_mac.py` が USB で直接書く。
- `-O0` でビルドすること。`-Os` だと純正サンプルすら立たない。
- memmap は 360 バイトあるが、USB とフラッシュ保存は先頭 352 バイトだけ (GAIN_OPTION6 は範囲外)。
- USB 通信: 64 バイトの HID レポート。`'R', 番地(下位,上位), 長さ` で読み、`'W', 番地, 長さ, データ` で書く、
  `'F','M'` でフラッシュ保存。0x1000 番地からはログ用バッファ (srcbuf)。
